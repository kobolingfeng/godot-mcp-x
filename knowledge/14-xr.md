# XR (VR/AR) — Godot 4.7

OpenXR-based XR. All classes below are **✅ verified** on 4.7.

## Minimum scene

```
XROrigin3D                 # the play-space origin (the "tracking volume")
├─ XRCamera3D              # the HMD — follows the headset
├─ XRController3D (left)   # tracker = "left_hand"
└─ XRController3D (right)  # tracker = "right_hand"
```
`XROrigin3D` ✅, `XRCamera3D` ✅, `XRController3D` ✅ (all extend `XRNode3D` ✅).
`XRAnchor3D` ✅ anchors content to AR-detected surfaces.

## Initialize OpenXR

```gdscript
func _ready() -> void:
    var xr := XRServer.find_interface("OpenXR")          # XRServer ✅
    if xr and xr.is_initialized():
        get_viewport().use_xr = true                      # render to the headset
        DisplayServer.window_set_vsync_mode(DisplayServer.VSYNC_DISABLED)
```
Usually you also enable OpenXR in **Project Settings → XR → OpenXR → Enabled** and
set the rendering method appropriately. `OpenXRInterface` ✅ exposes session state
signals (`session_begun`, `session_stopping`, …) and `OpenXRHand` ✅ for hand poses.

## Controllers & input

`XRController3D` reads an action-map (the OpenXR action set, separate from the
classic InputMap):
```gdscript
func _process(_d):
    if $LeftController.is_button_pressed("trigger_click"): fire()
    var stick := $LeftController.get_vector2("primary")   # thumbstick
# signals: button_pressed(name), button_released(name), input_float_changed, …
```
`XRControllerTracker` ✅ is the underlying tracker object.

## Body / hand / face tracking modifiers (SkeletonModifier3D family)

Drive a rigged `Skeleton3D` from XR tracking — add these as children of the skeleton
(see [10-skeleton-ik-and-modifiers.md](10-skeleton-ik-and-modifiers.md)):
- `XRBodyModifier3D` ✅ — full-body tracking → bones
- `XRHandModifier3D` ✅ — hand/finger tracking → hand skeleton
- `XRFaceModifier3D` ✅ — face/blendshape tracking

(godot-mcp-x: `add_skeleton_modifier {path, type:"XRHandModifier3D", …}`.)

## 4.7 XR specifics

- Production-ready **Android XR** and **Steam Frame** support.
- Improved **OpenXR composition layers** (e.g. crisp UI/video quads).
- Foundation Vulkan ray-tracing (`RDAccelerationStructure*`) is unrelated to XR but
  lands in the same release.

## Gotchas

- XR units are **meters** — model/scale your scene to real-world size.
- Move the player by translating the **XROrigin3D**, not the XRCamera3D (the camera
  is driven by the headset).
- The OpenXR **action map** is configured separately from the project InputMap.
- Comfort: keep a stable framerate; prefer teleport/vignette locomotion to avoid
  motion sickness.
